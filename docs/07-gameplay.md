# 7. Очки, уровни, достижения, рейтинг

## Формула очков

```
score = base × speedMultiplier + streakBonus
base   = difficulty² × 10 + 20        (1→30, 2→60, 3→110, 4→180, 5→270)
speed  = 1.0 … 1.3   — линейно от доли использованного времени (первые 20% → 1.3)
streak = min(серия, 10) × 5
```

Штрафов очков за отказ нет: наказание — потраченное время и обнуление серии.
Отрицательные баллы в социальных играх дают отток сильнее, чем удерживают от жульничества.

## Уровни

`XP += score`. Порог уровня N: `100 × N^1.6` (2→303, 5→1312, 10→3981, 20→12064).
Уровень открывает: доступ к заданиям сложности 4–5 (с 5 уровня), длинные серии,
кастомизацию профиля.

## Серия (streak)

Растёт за каждое одобренное задание. Обнуляется при: отказе от задания, истечении времени,
исчерпании попыток, пропуске суток без сдач. Ежедневная серия считается отдельно
(`dailyStreak`) и даёт множитель на первое задание дня.

## Достижения

Правила декларативные, хранятся в БД, проверяются после каждого одобрения
(`services/achievements.js`):

| Код | Условие | Название |
|---|---|---|
| `FIRST_BLOOD` | 1 одобренное | Первый кадр |
| `TEN_SHOTS` | 10 одобренных | Разогрев |
| `HUNDRED_SHOTS` | 100 одобренных | Сотня |
| `SPEED_DEMON` | выполнить за < 10% времени | Молния |
| `STREAK_5` / `STREAK_20` | серия 5 / 20 | На волне / Непрерывный |
| `NIGHT_OWL` | 5 сдач между 00:00 и 05:00 | Ночная смена |
| `POLYGLOT` | по одному в каждой категории | Всеядный |
| `SHARP_EYE` | 20 подряд без отказов | Точный глаз |
| `HARD_MODE` | 10 заданий сложности 5 | Тяжёлый режим |

Формат правила: `{"type":"approved_count","value":100}`, `{"type":"streak","value":20}`,
`{"type":"category_sweep"}`, `{"type":"time_window","from":0,"to":5,"value":5}`.
Новое достижение = строка в БД, кода писать не нужно.

## Рейтинг

Три периода: неделя, месяц, всё время. Неделя считается по сумме `score` сабмитов
за последние 7 дней (в проде — Redis ZSET с TTL, в dev — агрегация запросом).
Показывается топ-50 плюс окно ±2 позиции вокруг игрока — так виден ближайший соперник,
а это главный мотиватор в такой механике.

Античит рейтинга: игроки с `riskScore > 40` в публичный рейтинг не попадают до проверки.
