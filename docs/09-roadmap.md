# 9. План разработки

Оценки — для одного full-stack разработчика, работающего плотно.

## Этап 0. Каркас (сделано в этом репозитории)

Схема БД, API, антифрод-пайплайн, интеграция с Claude, 14 экранов, сид-данные.
Приложение запускается и играется локально.

## Этап 1. Довести до пилота — 2 недели

- [ ] Перевести на PostgreSQL, написать миграции
- [ ] S3-хранилище вместо диска, подписанные ссылки, превью 512px
- [ ] Refresh-токены с ротацией, выход со всех устройств
- [ ] Cron-наполнение пула заданий + догоняющий воркер для `PENDING`
- [ ] Sentry, структурные логи, `/health` и `/metrics`
- [ ] Тесты: unit на скоринг/антифрод, e2e на сценарий «задание → фото → вердикт»

## Этап 2. Пилот на 50–200 игроках — 3 недели

- [ ] Собрать 2000+ размеченных сабмитов, откалибровать пороги confidence и blur
- [ ] Замерить долю ложных отказов, цель < 3%
- [ ] Уведомления (Web Push), PWA-установка, офлайн-заглушка
- [ ] Админка: очередь спорных, массовые действия, экспорт CSV
- [ ] Юридический минимум: политика приватности, согласие на обработку фото, удаление аккаунта

## Этап 3. Публичный запуск — 4 недели

- [ ] Redis: rate-limit, лидерборд ZSET, кэш пула
- [ ] Горизонтальное масштабирование API, CDN на превью
- [ ] Антифрод-слой поведения: мультиаккаунты, аномалии скорости
- [ ] Соревновательные раунды или гео-режим (по решению из открытых вопросов)
- [ ] A/B на формулу очков и длительность заданий

## Этап 4. Развитие

Команды и клубы, сезоны с обнулением рейтинга, пользовательские задания с ИИ-валидацией,
нативные приложения с аттестацией устройства, партнёрские задания (бренды, музеи, туризм).

## Риски

| Риск | Митигация |
|---|---|
| Ложные отказы ИИ → отток | калибровка на реальных данных, 3 попытки, мягкие формулировки, ручной пересмотр |
| Стоимость vision-модели | локальный отсев, кэш по pHash, дешёвая модель на лёгких заданиях |
| Обход веб-камеры | сессионные токены, поведенческий антифрод, нативный клиент как план Б |
| Приватность людей в кадре | формулировки через предмет, размытие лиц, отказ от биометрии |
| Травмы игроков на улице | предупреждение в задании, запрет на опасные локации в промпте, дисклеймер при регистрации |
