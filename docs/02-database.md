# 2. База данных

Схема-источник истины: `server/prisma/schema.prisma`. Ниже — смысл сущностей и связей.

## Сущности

**User** — игрок. Денормализованы `points`, `xp`, `level`, `streak`, `submissionsApproved`:
лидерборд и профиль читаются без агрегаций. Пересчёт — ночной сверочный джоб.

**Task** — шаблон задания из пула. `criteria` (JSON) — то, что реально проверяет ИИ:
```json
{
  "object": "легковой автомобиль",
  "attributes": { "color": "красный" },
  "must_be_visible": ["кузов целиком"],
  "reject_if": ["игрушечная машина", "фото экрана"],
  "ocr_expect": null
}
```
`difficulty` 1–5, `points` считается формулой (см. `services/scoring.js`), `timeLimitSec` —
время на выполнение после принятия.

**Assignment** — факт выдачи задания игроку. Ключевая антифрод-сущность: `nonce`,
`issuedAt`, `expiresAt`, `attempts`. Одно активное задание на игрока (правило можно
ослабить в настройках).

**CaptureSession** — сессия камеры: токен выдаётся при открытии камеры, живёт 5 минут,
одноразовый. Сабмит без валидного токена отклоняется.

**Submission** — попытка сдачи. Хранит путь к фото, метрики (`phash`, `blurScore`,
ширина/высота/байты), сырой вердикт ИИ (`aiVerdict`), итог, начисленные очки и латентность.
Не удаляется даже при отказе — это материал для тюнинга антифрода.

**FraudEvent** — сработавшее правило (дубликат, фото экрана, подозрение на генерацию,
аномальная скорость). Накопление событий повышает `riskScore` пользователя.

**Achievement / UserAchievement** — правила достижений декларативные (`rule` JSON),
проверяются после каждого одобренного сабмита.

**Notification** — «задание проверено», «получено достижение», «место в рейтинге выросло».

**AuditLog** — действия модераторов и админов.

## Связи

```
User 1─n Assignment n─1 Task
User 1─n Submission n─1 Assignment
User 1─n FraudEvent
User n─n Achievement (через UserAchievement)
User 1─n Notification
```

## Индексы

| Таблица | Индекс | Зачем |
|---|---|---|
| Submission | `(userId, createdAt desc)` | история игрока |
| Submission | `(phash)` | поиск дубликатов |
| Submission | `(status, createdAt)` | догоняющая проверка PENDING |
| Assignment | `(userId, status)` | активное задание |
| User | `(points desc)` | лидерборд |
| Task | `(active, difficulty)` | подбор пула |

## Дедупликация фото

Хранится 64-битный dHash. Дубликатом считается совпадение с расстоянием Хэмминга ≤ 6:
- по всем сабмитам этого игрока за всё время → жёсткий отказ;
- по чужим сабмитам за 90 дней → отказ + `FraudEvent{type: STOLEN_PHOTO}`.

В PostgreSQL хэш кладётся в `BIGINT`, поиск — по индексу + фильтр по popcount(xor).
На SQLite (dev) сравнение делается в приложении по последним 5000 записям.

## Ретеншн

- оригиналы фото — 90 дней, дальше только превью 512px и хэш;
- отклонённые фото — 30 дней;
- `FraudEvent` и `AuditLog` — 2 года;
- удаление аккаунта: анонимизация `User`, физическое удаление фото в течение 30 дней (GDPR).
