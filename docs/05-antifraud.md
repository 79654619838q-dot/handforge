# 5. Антифрод

Каскад: дешёвые детерминированные проверки → ИИ → пост-анализ поведения.
Порядок важен — 30% попыток отсекается до вызова vision-модели.

## Слой 0. Происхождение кадра

| Механика | Что даёт |
|---|---|
| Только `getUserMedia` + canvas, нет `<input type=file>` | нельзя выбрать файл из галереи в UI |
| `captureToken` (одноразовый, 5 мин, привязан к assignment) | отправка через curl без открытия камеры не проходит |
| `nonce` выдачи задания | фото нельзя переиспользовать для другой выдачи |
| `elapsedMs` между открытием камеры и отправкой | мгновенная отправка (< 800 мс) подозрительна |
| Соответствие разрешения кадра заявленным габаритам трека | подмена буфера заметна |

Это не защита от целеустремлённого реверс-инжиниринга (веб-клиент всегда можно эмулировать),
а фильтр от массового жульничества. Полная гарантия происхождения кадра возможна только
через нативное приложение + Play Integrity / App Attest — см. открытые вопросы.

## Слой 1. Свойства файла

- размер 50 КБ … 8 МБ, разрешение ≥ 640×480, соотношение сторон 0.4…2.5;
- **резкость**: дисперсия Лапласиана по grayscale-версии 512px; `< 40` → отказ `BLURRY` (порог занижен намеренно: ложный отказ дороже пропуска);
- EXIF: наличие `Software` из списка редакторов (Photoshop, Snapseed, Facetune…) → флаг;
  отсутствие EXIF нормально (canvas его не пишет) и само по себе не наказывается;
- средняя яркость и клиппинг: полностью тёмный/белый кадр → отказ `LOW_QUALITY`.

## Слой 2. Дубликаты

64-битный dHash, расстояние Хэмминга:

| Совпадение | Действие |
|---|---|
| ≤ 6 с собственным прошлым фото | `DUPLICATE`, попытка сгорает |
| ≤ 6 с чужим фото (90 дней) | `DUPLICATE` + `FraudEvent{STOLEN_PHOTO}`, +25 к riskScore |
| ≤ 10 и одинаковый EXIF-timestamp | флаг на ручной пересмотр |

**Измерено на тестовых изображениях** (`server/scripts/calibrate.mjs`), расстояние Хэмминга
от оригинала:

| Преобразование | Расстояние | Ловится при пороге 6 |
|---|---|---|
| ресайз до 800px + JPEG q60 | 3 | да |
| ресайз до 480px | 3 | да |
| кроп 5% по краям | 10 | нет |
| поворот на 3° | 18 | нет |
| другое изображение | 32 | — |

То есть «пересохранить в другом качестве» не помогает, а обрезать края или повернуть —
помогает. Это известное ограничение dHash. Поднимать порог до 10-12 нельзя: вырастут ложные
срабатывания на однотипных кадрах (два разных снимка одной стены дают близкие хэши).
Правильное решение на этапе 3 — дополнить хэш матчингом по ключевым точкам (ORB/AKAZE),
устойчивым к повороту и кропу. До тех пор основной барьер против переиспользования —
`captureToken` и `nonce`, а не хэш.

## Слой 3. ИИ-флаги

Vision-модель отдельно отвечает на четыре вопроса, и каждый — жёсткий отказ:

- `screen_or_print` — съёмка монитора/телефона/распечатки (муар, рамка, блики, растр);
- `ai_generated` — признаки генерации (артефакты рук и текста, неестественная симметрия,
  «пластиковые» текстуры, отсутствие оптических дефектов);
- `edited` — следы монтажа (несогласованные тени, ореолы, разный шум по областям);
- `blurry` / `night_unclear` — объект нельзя разобрать.

Модель — не единственный судья: её флаги комбинируются с локальными метриками в
`services/verification.js`. Для `screen_or_print` дополнительно работает эвристика
на регулярный муар (высокочастотный пик в спектре) — резерв на будущее, точка расширения
помечена в коде.

## Слой 4. Поведение

Аномалии, которые считает `services/antifraud.js` по окну в 24 часа:

- средняя скорость выполнения ниже физически правдоподобной (объект найден за 20 секунд подряд 5 раз);
- сдача из одной GPS-точки при заданиях, требующих разных локаций;
- всплеск отказов подряд (перебор фото);
- один и тот же `deviceRatio` + IP у 5+ аккаунтов → мультиаккаунт;
- ночная активность в объёме, невозможном для одного человека.

`riskScore` 0–100: > 40 — сабмиты идут на ручную модерацию, > 70 — временная блокировка
и уведомление админу.

## Что мы принципиально не делаем

- не сохраняем сырые GPS-координаты дольше 30 дней (только гео-хэш 5 знаков);
- не распознаём лица и не строим биометрический индекс;
- не сохраняем распознанные автомобильные номера — только флаг совпадения с заданием.
