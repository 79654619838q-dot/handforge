# 4. Работа искусственного интеллекта

Две независимые функции: **генерация заданий** и **проверка фотографий**.
Обе в `server/src/services/ai.js`, промпты — в `server/src/services/prompts.js`.

## Модели

| Задача | Модель | Почему |
|---|---|---|
| Генерация заданий | `claude-haiku-4-5-20251001` | текстовая, объёмная, дешёвая; качество достаточное |
| Проверка фото | `claude-sonnet-5` | зрение высокого разрешения, нужна точность вердикта |
| Спорные случаи (confidence 0.4–0.6) | `claude-opus-5` | второй проход только на 5–8% сабмитов |

Все три поддерживают изображения на входе. Модель задаётся в `.env` — менять код не нужно.

## Генерация заданий

Вход: `{count, city, difficultyMix, excludeTitles}`. Выход — строгий JSON-массив:

```json
[{
  "title": "Красный автомобиль",
  "description": "Найдите и сфотографируйте припаркованный красный легковой автомобиль",
  "category": "TRANSPORT",
  "difficulty": 2,
  "timeLimitSec": 1800,
  "criteria": {
    "object": "легковой автомобиль",
    "attributes": {"color": "красный"},
    "must_be_visible": ["кузов автомобиля целиком или почти целиком"],
    "reject_if": ["игрушечная или модельная машина", "изображение на экране", "рекламный баннер"],
    "ocr_expect": null
  }
}]
```

Категории: `TRANSPORT · PEOPLE · ARCHITECTURE · SIGNS · NATURE · ANIMALS · STREET_OBJECTS · TEXT_AND_NUMBERS`.

Правила в промпте (главное, что удерживает качество):
- задание выполнимо в любом городе за отведённое время, без частной территории;
- не толкать игрока на риск (дорога, стройка, чужая собственность);
- **людей — только в публичном контексте и без узнаваемого крупного плана лица** (см. приватность);
- проверяемость: критерий должен быть определим по одному кадру;
- никаких заданий, требующих проникновения, взлома, конфликта с людьми.

Наполнение пула: cron раз в час добирает пул до `TASK_POOL_MIN` (по умолчанию 60 активных),
дубли отсекаются по нормализованному заголовку. Генерация идёт батчами по 12 заданий.

## Проверка фотографии

На вход модели уходит: JPEG (ресайз по длинной стороне до 1568 px, качество 82),
текст задания, `criteria` и сигналы предварительных проверок
(`blurScore`, `elapsedMs`, разрешение, наличие EXIF).

Ответ — только JSON:

```json
{
  "match": true,
  "confidence": 0.93,
  "object_visible": true,
  "quality": "good",
  "flags": {
    "blurry": false,
    "screen_or_print": false,
    "ai_generated": false,
    "edited": false,
    "night_unclear": false
  },
  "detected": ["красный седан", "бордюр"],
  "extracted_text": null,
  "reasons": ["В кадре красный седан, кузов виден целиком"]
}
```

Решение принимает не модель, а `services/verification.js`:

```
match && confidence >= 0.75 && !flags.*        → APPROVED
match && confidence 0.45..0.75                 → второй проход на opus-5
любой flag = true                              → REJECTED + FraudEvent
!match                                         → REJECTED (NO_MATCH)
таймаут / ошибка API                           → PENDING, догоняющий воркер, игрок не наказан
```

Порог `confidence` вынесен в настройки и должен калиброваться на реальных данных: держите
долю ложных отказов ниже 3%, это главный фактор оттока.

## Распознавание текста и номеров

Отдельного OCR-сервиса нет — Claude извлекает текст из кадра сам и возвращает
`extracted_text`. Для заданий вида «найти дом №67» сверка идёт нормализованным сравнением
(регистр, пробелы, кириллица/латиница-омоглифы). Для автомобильных номеров возвращается
только факт совпадения формата — **сам номер не сохраняется** (см. приватность).

## Стоимость

Ориентир на 1 сабмит: ~1 изображение 1568px (~1.1k токенов) + ~700 токенов промпта +
~200 токенов ответа. При 10k сабмитов/день это порядка десятков долларов в день на
`sonnet-5`. Рычаги снижения: локальный отсев до ИИ (уже даёт −30%), кэш по pHash,
превью 1024px для лёгких заданий, `haiku` для difficulty 1–2.

## Приватность людей в кадре

Задания с людьми («мужчина в шляпе», «девушка с зонтом») законны при съёмке в публичном
месте, но: ИИ не идентифицирует личность, лица не сохраняются в поисковом индексе,
на превью в истории/рейтинге лица размываются автоматически. Задание формулируется так,
чтобы объектом была деталь (шляпа, зонт), а не человек. Это же требование зашито в промпт генератора.
