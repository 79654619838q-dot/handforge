# 6. Экраны и пользовательские сценарии

14 экранов, все реализованы в `web/src/pages`.

| Экран | Файл | Суть |
|---|---|---|
| Вход | `Login.jsx` | email + пароль, ссылка на регистрацию |
| Регистрация | `Register.jsx` | email, ник, пароль; сразу выдаётся первое задание |
| Главная | `Home.jsx` | активное задание с таймером, короткая статистика, вход в камеру |
| Задания | `Tasks.jsx` | пул: сложность, очки, категория, фильтр |
| Задание | `TaskDetail.jsx` | описание, критерии, «Открыть камеру» |
| Камера | `Camera.jsx` | видоискатель, съёмка, предпросмотр, отправка |
| Проверка | `Verifying.jsx` | стадии проверки в реальном времени |
| Результат | `Result.jsx` | вердикт, разбор очков, причины отказа, следующее задание |
| Профиль | `Profile.jsx` | уровень, XP, серия, точность, разбивка по категориям |
| Рейтинг | `Leaderboard.jsx` | неделя / месяц / всё время, своя позиция |
| История | `History.jsx` | контактный лист превью с вердиктами |
| Достижения | `Achievements.jsx` | полученные и прогресс по остальным |
| Уведомления | `Notifications.jsx` | лента событий |
| Настройки | `Settings.jsx` | камера, уведомления, приватность, выход, удаление аккаунта |
| Админка | `Admin.jsx` | метрики, генерация заданий, лента сабмитов, антифрод, игроки |

## Основной сценарий (60–90 секунд)

1. Главная → активное задание «Красный автомобиль», таймер 29:41.
2. «Открыть камеру» → запрос разрешения (объясняем зачем до системного диалога —
   иначе половина пользователей жмёт «Запретить» и не возвращается).
3. Видоискатель с рамкой кадрирования и напоминанием критерия сверху.
4. Спуск → предпросмотр → «Отправить» / «Переснять».
5. Экран проверки: три стадии — загрузка, проверка подлинности, проверка ИИ.
6. Результат: +145 очков, разбор бонусов, новое задание.

## Отказ

Показываем причину человеческим языком и что делать: «Объект не найден в кадре.
На фото не видно автомобиля целиком — подойдите ближе и снимите кузов». Даём
`attemptsLeft` (по умолчанию 3 на выдачу), после исчерпания — новое задание без штрафа очков,
но с обнулением серии. Мягкость здесь важнее строгости: ложные отказы неизбежны,
а обида на них — главный источник оттока.

## Пустые состояния

- нет активного задания → крупная кнопка «Взять задание», а не пустой список;
- камера запрещена → инструкция, как включить в настройках браузера, для iOS и Android отдельно;
- нет истории → «Здесь появятся ваши кадры» + кнопка к пулу заданий.

## Дизайн-система

Экран камеры — сердце приложения, поэтому оболочка тёмная: нет вспышки белого при
переходе в видоискатель и обратно.

- цвет: `--ink #0E1116`, `--slab #151B23`, `--line #263041`, сигнальный жёлтый `#F2C43D`
  (очки, активное), зелёный `#3ED598` (принято), оранжевый `#FF6B4A` (таймер, отказ);
- шрифты: `Archivo` (заголовки, узкий гротеск городской навигации), `IBM Plex Sans` (текст),
  `IBM Plex Mono` (очки, таймеры, ID заданий);
- фирменный элемент — уголки видоискателя: обрамляют активное задание, кадр в истории,
  результат проверки. Один мотив на всё приложение;
- доступность: фокус видим, `prefers-reduced-motion` уважается, контраст текста ≥ 4.5:1,
  цель нажатия ≥ 44 px.
